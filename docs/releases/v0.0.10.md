## Highlights ⭐️

* **First lockstep release (`0.0.10`) of `passmcp-sdk-typescript`**: Apache-2.0 TypeScript MCP client and server SDK covering protocol revisions `2025-06-18`, `2025-11-25`, and `2026-07-28`, including capability-gated JSON-RPC dispatch, stateless `server/discover`, SEP-2164 unknown-resource errors, SEP-2549 list cache hints, strict HTTP `Origin` validation, and read-only-by-default client execution (`ADR 0013`).
* **Offline `passmcp` attestation verification**: validates `in-toto` `Statement/v1` (`mcp-evaluation/v1`) statements without network calls, recomputing SHA-256 and SHA-512 target descriptors byte-identically to `passmcp-reporting`.
* **Verified `100/100` (`Grade A`) under `passmcp check --stdio`**: ships runnable server and quickstart examples with `0` failures and `0` warnings.
